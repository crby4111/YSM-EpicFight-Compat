# 默认动作与配置回退

正式使用的默认策略为史诗战斗：没有 `config/ysm_epicfight_compat/motion_rules.json` 时，使用启用状态、空覆盖和空额外层的规则。首次读取配置失败也保留这套安全默认值；不会为了生成配置而写入游戏目录。

用户填写覆盖与额外层后，按各自条件执行，不根据攻击或受伤状态追加隐藏否决。显式设置 `"enabled": false` 可恢复旧的兼容路径。

热更新先完整读取规则及额外动作资源，再一次发布新快照。规则语法错误、资源读取失败或超限时，保留上一份有效规则和动作资源，版本号不前进，并输出错误原因。修正后重新加载即可生效。删除配置文件后恢复空规则下的默认 EF。

配置命令：`/ysmcompat rules reload`；检查模式与失败原因：`/ysmcompat rules status`。修改后应以游戏内实际重载和姿态为验收依据，离线配置测试不代表 R04 全部通过。
